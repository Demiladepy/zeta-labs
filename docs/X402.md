# x402 merchant (Phase 3)

Zeta’s demo merchant is the **pay-kit playground API**. Channel `deposit` / draw amount must match the route’s advertised ceiling.

## Start merchant (devnet)

From repo root (pay-kit cloned at `C:\Projects\pay-kit` by default):

```powershell
.\scripts\start-paykit-playground.ps1
```

Set in `scripts/devnet.env`:

```env
NETWORK=devnet
RPC_URL=https://api.devnet.solana.com
```

**Faucet:** `PLAYGROUND_FAUCET_URL` only works on **localnet**. On devnet, fund wallets with USDC via [Circle faucet](https://faucet.circle.com/) (Solana Devnet).

## Two x402 paths (important)

| Path | Endpoint | When to use |
|------|----------|-------------|
| **Integrated seven-step** | `GET http://127.0.0.1:3000/api/v1/fortune` | `npm run devnet:spend-submit -- --submit` (no `--skip-x402`). Uses x402 **exact**; vault channel from `draw` is settled separately (`hasVoucher=false`). |
| **Standalone smoke** | `POST …/summarize` (upto) | `npm run x402:smoke`. Agent wallet pays via PayKitClient (opens its own channel). **Not** combinable with vault `draw` in one flow today. |

Vault `draw` opens a channel with the **pool PDA** as token payer. Playground **upto** expects the **agent wallet** to open the channel in the x402 payload — those models conflict. Use **fortune** for integrated live x402 until pay-kit supports resuming an existing vault channel.

## Amount alignment

| Route | Playground price | Draw / deposit (base units) |
|-------|------------------|-----------------------------|
| `POST …/summarize` | `usage(usd('0.1'))` | 100_000 |
| `GET …/fortune` | `usd('0.01')` | 10_000 |

## One-time devnet playground setup

If payments fail with 402 / `invalid_exact_svm_transaction_simulation_failed`, fund the playground operator once (from your lender key):

```bash
cd packages/sdk
npx tsx scripts/fund-playground-fee-payer.ts      # ~0.5 SOL to fee payer
npx tsx scripts/ensure-playground-payee-usdc-ata.ts  # merchant USDC ATA
```

## Commands

```bash
cd packages/sdk
npm run devnet:phase3-preflight
npm run check-devnet-usdc          # agent wallet ≥100k for smoke
npm run x402:smoke                 # summarize / standalone
npm run devnet:spend-submit -- --submit   # set X402_ENDPOINT to /fortune for live x402
```

SDK helpers: `packages/sdk/src/x402-merchant.ts`, `packages/sdk/src/paykit/x402-http.ts`.
