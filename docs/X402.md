# x402 merchant (Phase 3)

Zeta’s demo merchant is the **pay-kit playground API** on devnet. Channel `deposit` / draw amount must match the route ceiling (see `x402-merchant.ts`).

## Start merchant (devnet)

```powershell
.\scripts\start-paykit-playground.ps1
```

`scripts/devnet.env`:

```env
NETWORK=devnet
RPC_URL=https://api.devnet.solana.com
X402_ENDPOINT=http://127.0.0.1:3000/api/v1/summarize
```

Fund the **agent/lender** with devnet USDC ([Circle faucet](https://faucet.circle.com/)). The HTTP x402 leg pays from the agent wallet; vault `draw` uses pool USDC.

## One-time devnet playground setup

If x402 returns 402 / simulation errors:

```bash
cd packages/sdk
npx tsx scripts/fund-playground-fee-payer.ts
npx tsx scripts/ensure-playground-payee-usdc-ata.ts
```

## Integrated seven-step (Anurag canonical path)

```
evaluate → vault draw (pool channel) → HTTP 402 upto/exact → operator settle → repay
```

| Endpoint | Scheme | Draw / deposit (base units) |
|----------|--------|-----------------------------|
| `POST …/summarize` | upto | 100_000 |
| `GET …/fortune` | exact | 10_000 |

```bash
npm run devnet:spend-submit -- --submit
```

`npm run x402:smoke` — standalone pay-kit client check (same endpoints).

## SDK

- `packages/sdk/src/x402-merchant.ts` — amounts + endpoint helpers
